# Blender guide

Current file: `02_Blender/01_Scenes/DC_Exterior_v04.blend` (Blender 5.2 LTS).
Older versions (v01 to v03) are kept next to it and in the Git history.

## Opening the file

1. Open the `.blend` in Blender 5.2 or newer.
2. The viewport shows the model without grass, so it stays fast. Grass is visible only in renders.
3. Press **Numpad 0** to look through the active camera. Change the active camera with *Scene properties → Camera*.

## Scene organisation

| Collection | Contents |
|---|---|
| `00_Site` | Ground, campus lawn, roads, pads, hills |
| `01_Batiment_Informatique` | IT building, fins, LEDs, sign, loading docks, rooftop dry coolers |
| `02_Batiment_Technique` | Technical building, louvres, chillers, link bridge |
| `03_Energie` | Generators, fuel tanks, transformers, gantries, pylons, HV cables |
| `04_Batiment_Logistique` | Glass building, NOC block, canopy, rooftop solar, glass link |
| `05_Parking` | Parking lot, carports, EV chargers, cars |
| `06_Securite` | Fence, gatehouse, barriers, bollards, CCTV |
| `07_Paysage` | Trees, street lights, cloud layer |
| `08_Lumieres_Cameras` | Sun (`KeySun`) and all cameras |
| `_Assets` (hidden) | Source grass tufts and the `_Hardscape` list used to keep grass off roads |

Naming rule: `Building_Part` in English, for example `IT_Facade_Fins` or `Generator_Exhausts`. Units are metres.

## Scripts

The whole campus is generated by Python. Both scripts live in `02_Blender/02_Scripts/` and are also embedded
in the `.blend`, in the Text Editor.

| Script | Purpose |
|---|---|
| `dc_lib.py` | Modelling helpers: `box`, `cyl`, `beam`, `text`, `join`, `coll`, `mat` |
| `dc_mat.py` | Material node builder `NB` (noise, voronoi, brick, ramps, bump…) used for the procedural materials |
| `render_drone_video.py` | Background render of the drone video, followed by MP4 encoding |

To use the helpers from Blender's Python console:

```python
exec(bpy.data.texts["dc_lib.py"].as_string())
box("My_Box", (2, 2, 2), (0, 0, 1), bpy.data.materials["Concrete_Pad"], coll("00_Site"))
```

## Geometry nodes

| Node group | Used on | What it does |
|---|---|---|
| `DC_GrassScatter` | `Site_Pad` | Scatters green grass tufts (2 per m²). Ray-casts against `_Hardscape` so no grass grows on roads or pads |
| `DC_GrassScatter_Ground` | `Ground` | Dry grass outside the fence (render currently switched off for speed) |
| `DC_Hills` | `Hills` | 5 km terrain that rises only beyond 520 m, so the horizon is not flat |

## Materials

All important materials are procedural, so they need no image files:

- asphalt with grain
- concrete with slab joints
- graphite cladding panels
- corrugated steel
- brushed aluminium
- painted generators with grime
- glass
- solar cells
- clear-coated car paint
- grass with subsurface scattering

Emission materials (`LED_Cyan`, `LED_Amber`, `LED_Red`, `Sign_White`, `Lamp_Head`) drive the glow, which the
compositor adds through the `DC_Compositor` node group (bloom and light lens dispersion).

## Rendering

### Stills (Cycles)

| Setting | Value |
|---|---|
| Engine | Cycles, GPU (OptiX, RTX 2050) |
| Samples | 160, adaptive, OptiX denoiser |
| Colour | AgX, *Medium High Contrast*, exposure −0.9 |
| Time | About 3–5 min per 1920 × 1080 image |

Switch the engine to Cycles, select a camera, then press **F12**. Save images to `02_Blender/04_Renders/stills/`.

| Camera | Shot |
|---|---|
| `CAM_Hero_SouthEast` | Main view: IT building, technical building, generators |
| `CAM_Entrance_Gate` | Public road, secure entrance, parking, logistique building |
| `CAM_Aerial` | Whole campus from above |
| `CAM_Power_Feed` | HV pylons, substation, technical area |
| `CAM_Logistique_NOC` | Logistique building and NOC at eye level |

### Drone video (EEVEE)

- Camera `CAM_Drone` follows the empty `CAM_Drone_Target`. The route: field → gate → NOC →
  IT facade → rooftops → generators → substation → HV lines → high reveal of the whole campus.
- 1,020 frames, 34 s at 30 fps, 1920 × 1080. Motion blur is on, with a small noise modifier for a real drone feel.
- EEVEE with ray tracing takes about 10 s per frame, so the full render takes about 3 h.
- Run it in the background (Blender stays usable):

  ```
  blender.exe -b 02_Blender/01_Scenes/DC_Exterior_v04.blend --python 02_Blender/02_Scripts/render_drone_video.py
  ```

  Frames are written to `04_Renders/animation/frames/` (ignored by Git). If the render stops, run the same
  command again: existing frames are skipped. The result is `04_Renders/animation/DC_Drone_Flythrough.mp4`.

To change the flight, edit the keyframes of `CAM_Drone` (position) and `CAM_Drone_Target` (where it looks) in
the Timeline or Graph Editor.

## Performance tips

- The grass is the heaviest part: about 120,000 tufts on the campus. Lower `Density` in the `DC_GrassScatter`
  group for faster renders.
- Keep grass disabled in the viewport (modifier *Realtime* off).
- For quick previews, set *Output → Resolution %* to 25–50 %.
