5. All verification commands for this profile

Run them all at once (about 10 min, PowerShell): python automation/verify_lab.py (last result: 59 PASS, 0 FAIL). Never use --disruptive just before the demo.

EDGE: Providers and edge routers

  1. EDGE-01: EDGE-A has its three BGP sessions (ISP-A, ISP-B, EDGE-B)
    WhereEDGE-A console (telnet 192.168.75.128 5004)
    show ip bgp summary
    Expect3 neighbours with a number in the last column (2, 1, 1). EDGE-B shows Idle until it has finished booting (always Idle in the demo profile, where EDGE-B is off).
  2. EDGE-03: EDGE-A holds the virtual gateway offered to the firewalls
    WhereEDGE-A console (5004)
    show standby brief
    ExpectGi0/3 group 1 Active, standby 10.254.1.3, virtual IP 10.254.1.6
  3. EDGE-04: The edge reaches the real Internet through its provider
    WhereEDGE-A console (5004)
    ping 8.8.8.8 repeat 5
    Expect"!!!!!", success rate 100 percent
  4. EDGE-05: OSPF is up between the two edges
    WhereEDGE-A console (5004)
    show ip ospf neighbor
    Expect2 lines FULL (Gi0/2 and Gi0/3)
  5. EDGE-06: The provider sees both edges and receives our prefix
    WhereISP-A auxiliary console (5037)
    vtysh -c "show ip bgp summary"
    Expect2 neighbours (EDGE-A, EDGE-B), PfxRcd 1 each
  6. EDGE-07: The provider container reaches the real Internet
    WhereISP-A auxiliary console (5037)
    ping -c 2 8.8.8.8
    Expect0% packet loss

    WhereFW-A shell (VNC 192.168.75.128:5900, option 8)

CORE: Core and leaf switches

  1. CORE-01: CORE-A is the gateway of its VLANs
    WhereCORE-A console (5010)
    show standby brief
    ExpectActive on Vl20, Vl40, Vl60, Vl100, Vl902; Standby on Vl30, Vl70, Vl80
  2. CORE-02: CORE-B is the gateway of the other VLANs
    WhereCORE-B console (5012)
    show standby brief
    ExpectActive on Vl30, Vl70, Vl80; Standby on the others
  3. CORE-03: The two links between the cores are bundled by LACP
    WhereCORE-A console (5010)
    show etherchannel summary | begin Group
    ExpectPo1(SU) with Gi0/2(P) Gi0/3(P). Shows (SD) while CORE-B is still booting.
  4. CORE-04: OSPF is up between the cores
    WhereCORE-B console (5012)
    show ip ospf neighbor
    Expect2 lines FULL (Vlan998 and Vlan902)
  5. CORE-05: The spanning-tree root of each VLAN is its active gateway
    WhereCORE-A console (5010)
    show spanning-tree root
    Expectno root port for VLAN 20, 40, 60, 100, 902, 998 (CORE-A is root); root port Po1 for 30, 70, 80
  6. CORE-06: The whole chain core, firewall, NAT, edge, provider works
    WhereCORE-A console (5010)
    ping 8.8.8.8 source vlan20 repeat 5
    Expect"!!!!!", source address 10.20.0.2
  7. CORE-07: Each leaf uplink forwards the VLANs of "its" core
    WhereLEAF-B1 console (5018) and LEAF-B2 console (5020)
    show interfaces trunk | begin Vlans in spanning
    ExpectGi0/0 forwards 20,40,60,100; Gi0/1 forwards 30,70,80
