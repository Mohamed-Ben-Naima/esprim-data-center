ESPRIM - Data Center Casablanca - 03_Network
Test the Lab
For each equipment: the command that proves it works, where to type it, and what you must see.

How to use this document

  • Each test has an identifier, the command, where to run it (node and console port) and the expected result.
  • Last passed is the date the test was really run and gave the expected result. "not run yet" means exactly that.
  • Each section says which nodes must be running. A test fails for the wrong reason if its path is not started.
  • Passwords are not printed here: they are in inventory/dc_casa.yaml (section credentials) and in appendix B of the lab guide.
  • Source of this document: report/tests/tests.yaml. Rebuild with python report/_source/build_lab_guide.py test_the_lab.

Before you test

Start what the test needs

# from the folder 03_Network, tier by tier, waiting for each tier
python automation/labctl.py start NAT-A NAT-B ISP-A ISP-B SW-OUT EDGE-A EDGE-B
python automation/labctl.py start SW-DMZ SW-MGMT FW-A FW-B SRV-WEB-01 ADMIN-WS
python automation/labctl.py start CORE-A CORE-B LEAF-B1 LEAF-B2
python automation/labctl.py start SYSLOG BMS-SIM CCTV-SIM SRV-DCIM-01 SRV-INF-01
python automation/labctl.py status

The PC cannot run everything at once. Leave hall A (LEAF-A1/A2) and the undeployed servers off, and check the host has free memory before starting SRV-MON-01.
