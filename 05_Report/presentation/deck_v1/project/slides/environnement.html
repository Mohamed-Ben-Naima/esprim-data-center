Partie 2 · Conception technique — Environnement de travail

Un PC portable qui porte tout le Data Center

  • GNS3 2.2.56 dans une VM VMware : QEMU pour Cisco et pfSense, Docker pour les services légers.
  • 15,7 Go de RAM : le labo démarre par profils (20 nœuds en démo).
  • Un inventaire YAML, 43 scripts : configs générées, déployées, vérifiées.

Comment c’est fait : lab_up.py démarre par étapes · inventory/dc_casa.yaml → gen_configs.py, gen_pfsense.py · Git + LFS

ISO 27001 A.8.9

Tout tourne sur un PC portable : Windows, VMware, et dans la VM GNS3, dix-huit machines QEMU et huit conteneurs. Avec 15,7 Go de mémoire, on ne peut pas tout démarrer ensemble, donc le laboratoire démarre par profils. Surtout, rien n’est configuré à la main : un seul fichier d’inventaire, et 43 scripts génèrent, déploient et vérifient les configurations.
