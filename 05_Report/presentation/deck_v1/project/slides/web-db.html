À gauche, le serveur web vu d’Internet : depuis l’opérateur, l’adresse publique répond, grâce à une redirection de port vers la DMZ. Et la DMZ ne peut joindre ni le management ni l’administration. À droite, la base de données : MariaDB derrière Zabbix, 173 tables, 128 Mo, sauvegardée chaque nuit et tirée par le NAS. Pas de serveur ajouté pour la forme : la base sert vraiment.
