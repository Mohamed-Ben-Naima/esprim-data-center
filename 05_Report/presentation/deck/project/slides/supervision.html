III.14 · Supervision (NOC)

Tout remonte à Zabbix, le NOC regarde Grafana

  • 18 hôtes Zabbix : SNMPv3 authPriv, agents, API, scénarios web.
  • Déclencheurs en français : chemin hors tension, baies dégradées, site en échec.
  • Nœuds éteints mis en maintenance automatiquement : zéro fausse alerte.

Comment c’est fait : zabbix_setup.py apply (hôtes depuis l’inventaire, API JSON-RPC via le proxy du labo)

ISO 27001 A.8.16

La supervision est entièrement configurée par script. zabbix_setup.py lit l’inventaire et crée les hôtes : les Cisco en SNMPv3 avec authentification et chiffrement, les pfSense en SNMP restreint au VLAN de supervision, les serveurs avec l’agent, BMS et DCIM par leur API JSON, le site web par un scénario. Les nœuds éteints dans le profil courant passent en maintenance, pour qu’aucune alerte ne soit fausse. Une coupure électrique remonte en moins de 10 secondes.
