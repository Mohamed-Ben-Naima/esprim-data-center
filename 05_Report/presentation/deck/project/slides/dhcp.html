III.7 · DHCP

DHCP : adressage statique par choix, relais conçu

En service

Adresses fixes

Serveurs et équipements ont une adresse fixe, écrite dans l’inventaire qui sert d’IPAM. Pas de bail qui expire sous un service critique.

Désactivé

DHCP de pfSense

Désactivé sur toutes les interfaces : pas de serveur DHCP pirate possible sur les VLAN du pare-feu.

Prévu

Pool + relais

Pool dnsmasq sur SRV-INF-01 (10.100.0.11) et ip helper-address sur les SVI des cœurs, pour des postes clients.

Comment c’est fait : gen_pfsense.py (DHCP off) · conception du relais dans PLAN_05 D17

ISO 27001 A.8.20

Nous préférons le dire clairement : il n’y a pas de serveur DHCP en service dans le labo. Dans un Data Center, les serveurs ont des adresses fixes ; c’est la bonne pratique, et notre inventaire joue le rôle d’IPAM. Le DHCP de pfSense est désactivé partout, ce qui évite un serveur DHCP non maîtrisé. Pour des postes clients, la conception est prête : un pool dnsmasq sur SRV-INF-01 et un relais ip helper-address sur les cœurs. Ce sera fait avec l’annuaire AD.
