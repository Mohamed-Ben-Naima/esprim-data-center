III.1 · Automatisation

Une source de vérité, tout le reste est généré

Comment c’est fait : 03_Network/automation/*.py · inventory/dc_casa.yaml (533 lignes)

ISO 27001 A.8.9

C’est le choix le plus important du projet. Un seul fichier YAML décrit le réseau : VLAN, adresses, ports, règles de pare-feu, ACL, tests. Les générateurs en tirent la topologie GNS3, les configurations Cisco, le config.xml de pfSense, les tableaux du rapport et le tableau Grafana. Les scripts de déploiement poussent, les audits comparent l’état réel à l’inventaire, et verify_lab rejoue le catalogue de tests. Changer le réseau, c’est changer une ligne et régénérer.
