ISO 27001 A.8.13

La base de données du projet est la vraie base de production de la supervision : MariaDB derrière Zabbix sur SRV-MON-01. Nous n’avons pas ajouté de serveur de base de données pour la forme. Elle compte 173 tables et pèse 128 Mo. Chaque nuit à 1 h 30 un dump est écrit localement, puis le NAS le tire à 2 h, en 110 secondes lors du dernier test. Détail de sécurité : pour cette capture, le mot de passe de la base a été déposé dans un fichier temporaire, jamais tapé en ligne de commande, car les commandes sont journalisées.
