III.8 · Serveur web

Le site public : Internet → NAT → DMZ

Depuis l’opérateur ISP-A, l’adresse publique 192.0.2.80 répond « OK SRV-WEB-01 » – 23/11/2026

  • SRV-WEB-01 : nginx dans la DMZ (VLAN 50, 10.50.0.11).
  • DNAT 192.0.2.80:80/443 → 10.50.0.11 (règle T18-1).
  • La DMZ ne peut joindre ni le management, ni l’administration (T18-9, journalisé).

Comment c’est fait : conteneur nginx:alpine · NAT et règles WAN/DMZ générés par gen_pfsense.py · test FW-06

ISO 27001 A.8.22

Le seul service exposé à Internet est le site web, dans la DMZ. Depuis le conteneur de l’opérateur ISP-A, donc depuis « Internet », on interroge l’adresse publique 192.0.2.80 : le pare-feu traduit vers 10.50.0.11 et nginx répond. La DMZ est cloisonnée : elle ne peut parler qu’à l’application sur le port 8443 et au DNS interne ; toute tentative vers le management ou l’administration est bloquée et journalisée.
