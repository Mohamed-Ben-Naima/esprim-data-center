  • Admin 90 atteint tout en SSH/HTTPS ; personne n’atteint Admin 90.

Comment c’est fait : firewall_rules + core_acl de l’inventaire · preuve report/evidence/flow_matrix.csv

ISO 27001 A.5.15

Toute la politique sur une page. Chaque ligne est une zone source, chaque colonne une destination. Les cases cyan sont les seuls flux autorisés, avec leurs ports ; les cases sombres sont refusées et journalisées. On voit la logique : la supervision interroge tout le monde, la sauvegarde tire depuis le VLAN 40, l’administration atteint tout en SSH et HTTPS, mais aucune zone ne peut entrer dans l’administration ni dans le management. Le script flow_matrix teste ces flux de bout en bout : zéro écart.
