Gestion de projet

Nous avons suivi six phases. Les phases 1 à 3 posent la conception et les visuels. Les phases 4 et 5 sont le réseau et les services dans GNS3. La phase 6 est la preuve : chaque exigence a un test, et chaque test laisse une trace datée dans report/evidence. Le travail est découpé en cinq plans successifs, versionnés dans Git avec leurs cases cochées.
