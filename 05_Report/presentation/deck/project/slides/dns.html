III.6 · DNS

Un DNS interne unique : SRV-INF-01

/etc/dnsmasq.d/dc-casa.conf
domain-needed
bogus-priv
no-resolv
server=1.1.1.1
server=8.8.8.8
domain=dc.casa.lab
local=/dc.casa.lab/
expand-hosts
listen-address=127.0.0.1,10.100.0.11

Extrait réel, poussé par deploy_servers.py --role=dns

  • dnsmasq sert la zone dc.casa.lab et relaie vers 2 résolveurs publics via le pare-feu.
  • Le résolveur de pfSense est désactivé : un seul DNS, une seule vérité.
  • Ouvert à tous les VLAN par l’ACL commune (UDP/TCP 53).

Comment c’est fait : deploy_servers.py rôle dns · services.dns = 10.100.0.11 dans l’inventaire

ISO 27001 A.8.21

Le DNS interne tourne sur SRV-INF-01, VLAN 100, avec dnsmasq : léger, il sert la zone interne et relaie le reste vers deux résolveurs publics, en sortant par le NAT du pare-feu. Nous avons volontairement désactivé le résolveur intégré de pfSense pour n’avoir qu’une source de noms. SRV-INF-01 porte aussi le NTP, la référence d’heure de tous les équipements.
