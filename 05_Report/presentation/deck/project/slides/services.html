III.3 · Services

Qui sert quoi, sur quel VLAN et quel port

  • Chaque service a une adresse fixe et ses ports dans l’inventaire.
  • Les ACL et le pare-feu n’ouvrent que ces ports.
  • La sauvegarde tire les données : aucun serveur n’écrit sur le NAS.

Comment c’est fait : servers + port_aliases dans l’inventaire · deploy_servers.py, deploy_containers.py

ISO 27001 A.8.21

Huit familles de services. Les services internes sont dans le hall B : DNS et NTP sur SRV-INF-01, journaux sur SYSLOG, supervision sur SRV-MON-01, GTB et DCIM. Le hall A porte l’application, avec une adresse virtuelle partagée par deux serveurs, et le stockage NFS et iSCSI. Le site web est seul dans la DMZ. Chaque port listé ici est exactement ce que les ACL et le pare-feu autorisent, rien de plus.
